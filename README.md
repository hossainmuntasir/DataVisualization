OECD Health Life Expectancy Analysis
This project is a web application that analyzes the health life expectancy of OECD countries. Hosted on GitHub, the application uses HTML, CSS, JavaScript, and D3.js to provide interactive visualizations. You can view and interact with the visualizations directly through the provided link.

Features
Interactive data visualizations created with D3.js
Three main visualizations:
Choropleth Map: Displays life expectancy on a world map with color variations.
Bar Chart: Shows demographic data by age and gender.
Life Expectancy Over Time: Compares life expectancy changes over time for selected OECD countries, with options to add or remove countries dynamically.
Dataset
The data for this project is obtained from the OECD Health Statistics database, providing reliable and up-to-date information on the health status and healthcare systems of OECD member countries.

Technologies Used
HTML: For structuring the web page
CSS: For styling the visual elements
JavaScript: For dynamic content and interactivity
D3.js: For data visualization and manipulation
